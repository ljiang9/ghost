# ghost 拼词游戏

终端版 Ghost 接龙拼词：两名玩家轮流给词片段追加一个字母，**拼出完整单词（≥4 字母）者输**；允许虚张声势（bluff），对方可质疑。

## 玩法

- 空片段开局，轮流加一个英文字母。
- 片段变成词表中的完整单词（≥4 字母）→ 加字母的人当场判负。
- 任何时候可输入 `!` **质疑**上家：上家必须证明当前片段能拼成单词——
  - 片段确实是某个单词的前缀 → 质疑失败，质疑者输；
  - 片段不是任何单词的前缀（上家在 bluff）→ 上家输。
- 3 字母及以下的"单词"不算输（如 `cat`），游戏继续。

## 用法

```bash
python3 -m ghost                  # 人机对战（你是玩家0先手）
python3 -m ghost --second         # 人机对战（你后手）
python3 -m ghost --auto --games 10 --seed 42   # AI 对 AI 自动演示
```

交互中输入单个字母走棋，输入 `!` 质疑。

## AI 说明

AI 为 **DP 最优走法**：内置词表建成前缀树（trie），对全部前缀做胜负 DP（记忆化），
有必胜走法必走之；对方 bluff（片段不是任何前缀）时必质疑。纯标准库，无外部依赖。

## 有趣的发现（已验证，非 bug）

用 DP 对全部 1536 个前缀穷举验证：**在这个内置词表下，后手有理论必胜策略**——
26 个首字母的每一种开局都会把先手送入"必输位"。因此 AI 对 AI 时先手胜率≈0，
这是该词表下 Ghost 的数学性质，不是程序 bug。换词表结论可能不同。

## 已知局限（诚实版）

- 内置词表约 350 个常见英文词，无专有名词；词表规模小，熟练玩家背下词表后可针对 AI。
- AI 假设对手不犯低级错误；人类用怪异 bluff 时 AI 只按规则质疑，无心理战。
- 文本界面，无图形/存档/悔棋/网络对战；Python 3.10+，纯标准库。
